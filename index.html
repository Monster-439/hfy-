                🌐 GitHub 云同步（私有仓库 · 永久保存）
                未连接

                数据存放在你自己的 GitHub 私有仓库里，永久保存、完全由你掌控。连接成功后，本机现有数据会一键上传到该仓库；之后任何一端改动都会自动同步，电脑 / 手机 / 平板三端在浏览器内保持一致。GitHub 在国内偶尔偏慢，属正常现象。

                Token
                仓库名
                怎么获取 Token？（点开）

                1. 打开 GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic)
                2. 点 Generate new token (classic)，勾选 repo 权限（若用细粒度令牌，则选 Contents: Read and write 并指定本仓库）
                3. 生成后复制那一串字符，粘到上方「Token」框即可。令牌只存在你这台浏览器，可随时在 GitHub 撤销。

                提示：本机数据始终先存浏览器，联网后自动与仓库同步；断网照常使用，恢复后自动补传。仓库内同步文件为 xckq-garden/sync.json。
